# .qwen Directory

This directory contains Qwen Code configurations and customizations that help tailor the AI assistant's behavior to this specific project.

## Files
- `QWEN.md` - Project-level configuration for Qwen Code
- This README explains the purpose of this directory

## Purpose
The files in this directory help Qwen Code understand:
- Project-specific context and technologies
- Preferred coding styles and conventions
- Testing approaches
- Development workflow preferences

When Qwen Code encounters this directory, it will use these configurations to provide more relevant and contextual assistance.
